# Papers to download for the QLFR re-implementation

Put the PDFs into one folder named `papers`, zip it as `papers.zip`, and either:
- **upload `papers.zip` in this chat**, or
- **upload the PDFs on GitHub** to `amritha902/underwater`, branch `claude/nice-lamport-w2ykc7`, folder `papers/` (Add file → Upload files).

Use exactly the file names below, so the scripts find them.

## 1. Required (the re-implementation can't be finished without it)

| Save as | Paper | Free link |
|---|---|---|
| `QLFR_arxiv_2002.09623.pdf` | Zhou, Cao, Xiang, "Anypath Routing Protocol Design via Q-Learning for Underwater Sensor Networks," IEEE IoTJ 2021 (base paper) | https://arxiv.org/pdf/2002.09623 |

## 2. Strongly recommended (exact baseline equations)

| Save as | Paper | Link |
|---|---|---|
| `QLFR_IEEE_JIOT2020.3042901.pdf` | Final IEEE version of the base paper (figures can differ from arXiv) | https://doi.org/10.1109/JIOT.2020.3042901 (needs IEEE access through a university library) |
| `DBR_Yan2008.pdf` | Yan, Shi, Cui, "DBR: Depth-Based Routing for Underwater Sensor Networks," NETWORKING 2008 | https://doi.org/10.1007/978-3-540-79549-0_7 (Springer; needs library access) |
| `VBF_Xie2006.pdf` | Xie, Cui, Lao, "VBF: Vector-Based Forwarding Protocol for Underwater Sensor Networks," NETWORKING 2006 | https://core.ac.uk/display/24603523 (free copy) or https://doi.org/10.1007/11753810_111 |
| `QELAR_Hu2010.pdf` | Hu, Fei, "QELAR," IEEE TMC 2010 | https://doi.org/10.1109/TMC.2010.28 (needs library access) |
| `DoubleQ_vanHasselt2010.pdf` | van Hasselt, "Double Q-learning," NIPS 2010 | https://papers.nips.cc/paper/3964-double-q-learning (free; click "Paper") |
